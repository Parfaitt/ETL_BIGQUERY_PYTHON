# Projet BigQuery - Chargement et Visualisation de Données

## Description
Ce projet a pour objectif de charger plusieurs fichiers CSV contenant des données financières et opérationnelles dans BigQuery, puis de les exploiter dans Looker Studio pour créer des dashboards interactifs et analytiques. 

Chaque CSV correspond à une table BigQuery, et les tables suivantes ont été créées :

- `account` : informations sur les comptes clients
- `card` : informations sur les cartes bancaires
- `client` : données clients
- `disp` : personnes disposant de comptes
- `district` : informations géographiques (districts)
- `loan` : informations sur les prêts
- `orders` : transactions financières
- `trans` : détails des transactions

---

## Outils utilisés

| Outil / Technologie | Utilisation |
|-------------------|-------------|
| **Python** | Script de chargement des CSV vers BigQuery |
| **Google BigQuery** | Stockage et gestion des données |
| **Looker Studio** | Visualisation et reporting interactif |
| **Google Cloud SDK** | Authentification et gestion du projet GCP |
| **Pandas** | Manipulation et conversion des données (facultatif pour visualisation) |
